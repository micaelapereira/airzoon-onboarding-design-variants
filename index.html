Onboarding — welcome + setup-status screen

The original two-panel reference plus four new layout directions for the same one-screen welcome/setup-status brief: a two-state checklist (done / in progress), no progress bar or percentage anywhere, the "Let's go" button disabled until all four checks pass, and each page a single self-contained HTML file — no external CSS, JS, or image files.

A fifth new direction (a very quiet, minimal layout) was dropped: its only way of showing progress was a percentage-style bar, which the brief explicitly rules out, and stripping that left nothing to distinguish it from the others. See README.md for the full reasoning.
